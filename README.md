Budget Tracker
Project Overview

This project is a visually improved Budget Tracker created using HTML and CSS.

The purpose of the project is to make a simple expense-tracking application look more professional, organized, and user-friendly through CSS design.

The project focuses on:

A consistent color palette

Custom Google Fonts

Styled forms and inputs

A professional expense table

Alternating table row colors

Buttons with hover effects

CSS Box Model techniques

Responsive design

style.css

The style.css file contains all of the visual styling for the application.

Color Palette

The project uses a consistent color palette based on navy blue, bright blue, white, and slate gray.

Blue is used for important interactive elements such as:

Buttons

Headings and accents

Form focus states

Expense category indicators

Navy blue is used for the table header and important headings.

Typography

Two Google Fonts are used:

Playfair Display - used for major headings.

DM Sans - used for body text, labels, forms, buttons, and table content.

This creates a clear visual hierarchy while keeping the application easy to read.

Form Styling

The Add Expense form has:

Consistent spacing

Padded inputs

Rounded corners

Borders

Focus effects

Styled labels

A professional blue button

Table Styling

The Expense History table includes:

A dark navy table header

White header text

Cell padding

Borders

Alternating row colors

Hover effects

Category badges

Green expense amounts

These features make the information easier to scan.

CSS Box Model

The CSS Box Model is intentionally used throughout the project.

The three main areas are displayed as separate cards:

Page Heading

Add Expense Form

Expense History Table

Each card uses:

margin to create space between sections

padding to create space inside sections

border to define the card edges

border-radius to create rounded corners

box-shadow to add depth

Design Goals

The main design goal was to transform a basic Budget Tracker into a clean and modern interface without adding unnecessary HTML functionality.

The design emphasizes:

Readability

Consistency

Clear visual hierarchy

Easy navigation

Professional appearance
